# ROSA CAD — PySide6

## Запуск в Windows

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

4. Запустите приложение:

```bash
python main.py
```

## Последние исправления

- Устранено полное пересоздание графической сцены при каждом выборе элемента: обновляется только подсветка выбранных узлов и стержней.
- Первоначальный вид схемы автоматически подгоняется под размер рабочей области.
- Штриховка опоры направлена слева снизу направо вверх.
- Индикаторы флажков имеют белый фон и контрастную галочку.
- WAV-файлы загружаются один раз и воспроизводятся через Qt Multimedia с системным резервным вариантом.

## Состав

- `main.py` — запуск приложения.
- `app.py` — главное окно и логика интерфейса.
- `graphics.py` — графическая сцена и взаимодействие со схемой.
- `config.py` — настройки, шрифты, стили и формат данных.
- `assets/` — изображения, шрифты и звуки.

Проекты по-прежнему хранятся в JSON. Проверяйте изменения на копиях файлов. Эта версия является препроцессором и не выполняет инженерный расчёт прочности.
